## 🔑 Key Concepts
- LEGB: Local → Enclosing → Global → Built-in
- `global` targets a global variable.
- `nonlocal` targets a variable in the nearest enclosing function scope.
- Reading a global variable does not require `global`.
- Assignment inside a function normally makes the name local unless declared otherwise.
- Local variables do not automatically modify global variables.
